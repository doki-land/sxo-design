`@sxo/component-icons` provides a set of highly optimized, framework-agnostic SVG icons designed specifically for the SXO ecosystem.

## ✨ Key Features

- 🎨 **SXO Aligned**: Icons are designed to perfectly match the SXO design language.
- ⚡ **Lightweight**: Optimized SVG paths for minimal bundle size.
- 🧩 **Modular**: Grouped by category (Basic, System, Social, etc.) for easy access.
- 🛡️ **Type Safe**: Full TypeScript support for icon names and components.

## 🚀 Quick Start

### Installation

```bash
pnpm add @sxo/component-icons
```

### Usage

```typescript
import { IconSearch, IconUser } from '@sxo/component-icons';

// Icons are provided as raw SVG data or path data for flexible rendering
console.log(IconSearch.path);
```
