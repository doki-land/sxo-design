# GitHub 风格主题设计语言

本设计语言仿照 GitHub 的视觉风格，强调简洁、高效与极客感，采用其标志性的蓝、绿、灰配色方案。

## 1. 安装

使用 npm 或 pnpm 安装主题包：

```bash
npm install @sxo/theme-github
# 或者
pnpm add @sxo/theme-github
```

## 2. 适用场景

- **开发者工具**：IDE、代码托管平台、CLI 工具等。
- **技术社区/文档**：极高的开发者认同感，适合展示代码和技术文档。
- **个人技术博客**：简洁、专业，适合展示个人项目和技术思考。

## 3. 设计语言

### 3.1 核心设计理念 (Core Concept)

- **关键词**：简洁、极客、开源、可靠。
- **视觉风格**：扁平化设计（Flat Design），减少装饰性元素，强调内容层次。
- **边框与阴影**：使用细边框（Hairline borders）区分区块，而非沉重的阴影。

### 3.2 色彩系统 (Color System)

#### 3.2.1 基础色 (Base Colors)

| 类型 | 色相 | 白天模式 (Light) | 黑夜模式 (Dark) | 用途 |
| :--- | :--- | :--- | :--- | :--- |
| **主色** | **蓝色 (Blue)** | `#0969DA` | `#58A6FF` | 链接、操作、选定状态 |
| **成功色** | **绿色 (Green)** | `#1A7F37` | `#3FB950` | 提交按钮、通过状态、贡献度 |
| **警示色** | **橙色 (Orange)** | `#AF4E12` | `#D29922` | 警告、待办、星星 |
| **危险色** | **红色 (Red)** | `#CF222E` | `#F85149` | 错误、删除、关闭状态 |
| **边框色** | **灰色 (Gray)** | `#D0D7DE` | `#30363D` | 分割线、容器边框 |

#### 3.2.2 背景与文字 (Surface & Text)

| 类型 | 白天模式 (Light) | 黑夜模式 (Dark) |
| :--- | :--- | :--- |
| **主背景** | `#FFFFFF` | `#0D1117` |
| **次背景** | `#F6F8FA` | `#161B22` |
| **主要文字** | `#1F2328` | `#E6EDF3` |
| **次要文字** | `#65717D` | `#8B949E` |

### 3.3 视觉元素规范 (Visual Elements)

#### 3.3.1 贡献度配色 (Contribution Palette)
- **等级 1**: `#9BE9A8` (Light) / `#0E4429` (Dark)
- **等级 2**: `#40C463` (Light) / `#006D32` (Dark)
- **等级 3**: `#30A14E` (Light) / `#26A641` (Dark)
- **等级 4**: `#216E39` (Light) / `#39D353` (Dark)

#### 3.3.2 圆角 (Border Radius)
- **标准圆角**：`6px`。GitHub 的风格偏向硬朗，圆角较小。

#### 3.3.3 字体 (Typography)
- **字体族**：`-apple-system, BlinkMacSystemFont, "Segoe UI", Helvetica, Arial, sans-serif`。

### 3.4 交互体验 (Interaction)

- **悬浮效果**：背景色微调或下划线提示。
- **状态切换**：即时响应，无过度动画，强调操作的确定性。
