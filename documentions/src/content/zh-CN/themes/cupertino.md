# Cupertino 主题规范

Cupertino 主题 (`@sxo/theme-cupertino`) 是对 Apple iOS 设计风格的极致还原。它强调质感、细腻的动画以及自然的交互体验。

## 安装

你可以通过 npm、yarn 或 pnpm 安装此主题包：

```bash
npm install @sxo/theme-cupertino
# 或者
yarn add @sxo/theme-cupertino
# 或者
pnpm add @sxo/theme-cupertino
```

## 适用场景

- **追求精致感的 2C 应用**：移动端 H5、精品工具类应用。
- **果粉群体产品**：希望营造出 iOS 原生应用体验的产品。
- **高端展示类网站**：需要高质感视觉表达的品牌页面。

## 设计语言

### 色彩系统

- **品牌色**：iOS System Blue (`#007aff`)，明亮且具有高度的识别性。
- **中性色**：采用 iOS 系统级灰阶，支持半透明质感，便于构建毛玻璃效果。
- **背景色**：典型的系统背景色（`#ffffff` / `#f2f2f7`），营造纯净的视觉底色。

### 形状与空间

- **大圆角**：默认圆角为 `12px`，带来圆润、亲和且安全感十足的视觉体验。
- **字体系统**：优先调用系统字体（`-apple-system`, `SF Pro`），确保与操作系统高度融合。

### 阴影与深度

- **阴影**：细腻且弥散的投影（Soft Shadow），模拟物体在自然光下的悬浮感。
- **空间感**：通过层级化的阴影和背景色，构建出符合直觉的三维空间结构。
