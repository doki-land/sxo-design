# Material Design 3 主题规范

Material Design 3 主题 (`@sxo/theme-material`) 遵循 Google 最新的 M3 规范。它强调“个人化”和“适应性”，通过灵活的色彩系统和充满活力的交互设计，为用户提供富有情感的体验。

## 安装

你可以通过 npm、yarn 或 pnpm 安装此主题包：

```bash
npm install @sxo/theme-material
# 或者
yarn add @sxo/theme-material
# 或者
pnpm add @sxo/theme-material
```

## 适用场景

- **2C 应用的首选**：移动端 H5、社交应用、内容分享平台。
- **充满活力的产品**：需要展现个性化和情感化设计的项目。
- **跨平台应用**：追求在不同设备上保持一致体验的产品。

## 设计语言

### 色彩系统

- **品牌色**：基于 M3 规范的 Primary 色值 (`#6750A4`)，提供丰富的色调调色板。
- **动态色彩**：支持 Material You 的核心理念，强调色彩之间的逻辑关联。
- **中性色**：温暖且具有层次感的灰阶系统（`N-100` 到 `N-900`）。

### 形状与空间

- **大圆角**：默认圆角为 `12px`，在按钮和卡片等容器上表现出极强的亲和力。
- **字体系统**：使用 `Roboto` 字体家族，具有极高的普适性和现代感。

### 阴影与深度

- **层级阴影**：基于高度（Elevation）的投影系统，清晰地定义了元素在 Z 轴上的位置。
- **交互反馈**：阴影与颜色的配合使用，为用户操作提供直观的视觉反馈。
