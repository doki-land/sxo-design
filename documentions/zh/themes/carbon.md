# Carbon 主题规范

Carbon 主题 (`@sxo/theme-carbon`) 遵循 IBM 的开源设计系统规范。它以冷色调、高对比度和严谨的网格系统为核心，致力于提供高效、清晰的数字化体验。

## 安装

你可以通过 npm、yarn 或 pnpm 安装此主题包：

```bash
npm install @sxo/theme-carbon
# 或者
yarn add @sxo/theme-carbon
# 或者
pnpm add @sxo/theme-carbon
```

## 适用场景

- **工业级仪表盘**：需要极高信息密度的专业监控界面。
- **数据分析平台**：追求极高操作效率和逻辑清晰度的工具。
- **专业技术中台**：面向开发者和技术人员的复杂业务系统。

## 设计语言

### 色彩系统

- **品牌色**：IBM Blue 60 (`#0f62fe`)，具有极强的视觉冲击力和专业感。
- **高对比度**：采用深色调的中性色系统，确保在专业环境下极高的信息识别率。
- **背景色**：分层明确的背景色系统（`#ffffff` / `#f4f4f4` / `#161616`）。

### 形状与空间

- **圆角**：**无圆角设计**（`0px`），强调工业感、严谨性和数字化的纯粹性。
- **字体系统**：默认使用 `IBM Plex Sans`，一款兼具功能性与现代美感的字体。

### 阴影与深度

- **阴影**：极其克制的阴影使用，主要通过线条和色块来区分区域，减少视觉干扰。
- **网格**：严格遵循 Carbon 2x 网格系统，确保每一个像素的布局都具有逻辑性。
