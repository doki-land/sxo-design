# 微信 (WeChat) 主题规范

微信主题 (`@sxo/theme-wechat`) 旨在复刻微信生态的视觉体验。它以稳重、简洁、高认知度为核心，适合在微信环境内运行或追求极致简约的系统。

## 安装

你可以通过 npm、yarn 或 pnpm 安装此主题包：

```bash
npm install @sxo/theme-wechat
# 或者
yarn add @sxo/theme-wechat
# 或者
pnpm add @sxo/theme-wechat
```

## 适用场景

- **微信生态应用**：小程序 H5、企业微信内部应用。
- **政务/金融系统**：需要传递稳重、可靠、普适感的专业系统。
- **追求极简主义的产品**：希望通过最简单的视觉语言传达核心信息的产品。

## 设计语言

### 色彩系统

- **品牌色**：微信绿 (`#07C160`)，具有极高的社会认知度和信任感。
- **辅助色**：微信蓝 (`#10AEFF`) 和微信红 (`#FA5151`)，用于特定的功能提示。
- **中性色**：经典的 WeUI 灰阶系统，色彩平衡且耐看。

### 形状与空间

- **标准圆角**：默认圆角为 `8px`，是 WeUI 的标准规范，平衡了严谨与友好。
- **字体系统**：优先使用微信内置的字体栈，确保在移动设备上的最佳阅读体验。

### 阴影与深度

- **克制阴影**：极轻量的投影效果，甚至在很多场景下使用 1px 的边框来替代阴影。
- **信息层级**：通过大面积的留白和细微的背景色差，构建出简洁清晰的信息结构。
