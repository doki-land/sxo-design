# Fluent 主题规范

Fluent 主题 (`@sxo/theme-fluent`) 遵循微软的 Fluent Design System 规范。它结合了光效、深度、材质和尺度，旨在创造一种现代、通透且富有生产力的设计体验。

## 安装

你可以通过 npm、yarn 或 pnpm 安装此主题包：

```bash
npm install @sxo/theme-fluent
# 或者
yarn add @sxo/theme-fluent
# 或者
pnpm add @sxo/theme-fluent
```

## 适用场景

- **办公协同软件**：文档协作、任务管理、邮件系统等。
- **企业内部工具**：现代化的企业级管理工具。
- **SaaS 平台**：追求美感与效率并重的云服务产品。

## 设计语言

### 色彩系统

- **品牌色**：Microsoft Brand Blue (`#0078d4`)，传递出稳重、可信赖的职业感。
- **中性色**：细腻的灰阶系统，强调层次的连贯性和过渡的自然性。
- **背景色**：通透的背景色（`#ffffff` / `#faf9f8`），营造轻量化的视觉氛围。

### 形状与空间

- **细腻圆角**：默认圆角为 `4px`，在保持严谨性的同时，增加了一份现代化的柔和感。
- **字体系统**：使用 `Segoe UI` 字体家族，提供极佳的文字识别度和专业感。

### 阴影与深度

- **深度感**：独特的阴影算法（基于多个阴影叠加），模拟出极具质感的深度层级。
- **现代感**：通过光影效果和细腻的边框处理，展现出 Windows 系统的现代设计美学。
