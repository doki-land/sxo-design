# Ant Design 主题规范

Ant Design 主题 (`@sxo/theme-antd`) 是专为 B 端后台管理系统设计的企业级主题。它遵循 Ant Design 的设计价值观，强调“自然”、“确定性”、“意义”和“生长”。

## 安装

你可以通过 npm、yarn 或 pnpm 安装此主题包：

```bash
npm install @sxo/theme-antd
# 或者
yarn add @sxo/theme-antd
# 或者
pnpm add @sxo/theme-antd
```

## 适用场景

- **B 端后台管理系统**：企业内部工具、管理后台、ERP 系统等。
- **数据密集型应用**：需要展示大量表格、表单和图表的专业应用。
- **追求确定性的产品**：需要极高的一致性和标准化的设计。

## 设计语言

### 色彩系统

- **品牌色**：Ant Design Blue (`#1677ff`)，提供稳重、专业的视觉感受。
- **中性色**：经过精确计算的灰阶系统，确保在不同背景下的可读性和对比度。
- **功能色**：严谨的成功、警告、错误和信息色，符合通用的设计直觉。

### 形状与空间

- **圆角**：默认圆角为 `6px`，在保持现代感的同时，展现出严谨的几何美感。
- **网格系统**：基于 8 像素栅格系统，确保组件间的间距精确且一致。

### 阴影与深度

- **阴影**：多层次的投影系统，用于区分不同的层级，模拟光线照射下的真实深度。
- **层次感**：通过背景色和边框的细微差异，构建清晰的信息层级结构。
