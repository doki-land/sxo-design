# GitHub Halloween 风格主题设计语言

本设计语言仿照 GitHub 万圣节期间的彩蛋风格，将经典的绿色贡献矩阵替换为富有节日气氛的橙紫色系，充满神秘感。

## 1. 安装

使用 npm 或 pnpm 安装主题包：

```bash
npm install @sxo/theme-halloween
# 或者
pnpm add @sxo/theme-halloween
```

## 2. 适用场景

- **节日活动页面**：适用于万圣节等特定节日期间的主题切换。
- **个性化展示**：为用户提供趣味性的视觉选择。
- **游戏/娱乐应用**：富有节日气氛的配色方案。

## 3. 设计语言

### 3.1 核心设计理念 (Core Concept)

- **关键词**：万圣节、南瓜、幽灵、趣味。
- **视觉风格**：基于 GitHub 基础框架，通过色彩变换营造节日氛围。
- **光影处理**：在深色模式下增加南瓜橙的微光感。

### 3.2 色彩系统 (Color System)

#### 3.2.1 基础色 (Base Colors)

| 类型 | 色相 | 白天模式 (Light) | 黑夜模式 (Dark) | 用途 |
| :--- | :--- | :--- | :--- | :--- |
| **主色** | **南瓜橙 (Pumpkin)** | `#ED6A43` | `#FF9668` | 核心操作、选定状态、高亮 |
| **辅色** | **幽灵紫 (Ghostly)** | `#8250DF` | `#A371F7` | 链接、次要操作 |
| **背景色** | **深渊黑 (Abyss)** | `#F6F8FA` | `#0D1117` | 页面基础背景 |
| **边框色** | **阴影灰 (Shadow)** | `#D0D7DE` | `#30363D` | 区块边界 |

#### 3.2.2 贡献度配色 (Halloween Contribution Palette)

万圣节主题的核心在于贡献矩阵的颜色变化：

| 级别 | 颜色名称 | 色值 (Light) | 色值 (Dark) |
| :--- | :--- | :--- | :--- |
| **等级 0** | 背景 | `#EBEDF0` | `#161B22` |
| **等级 1** | 幽灵紫 | `#FFEE4A` (南瓜黄) | `#631C03` (暗焦糖) |
| **等级 2** | 南瓜橙 | `#FFC501` | `#BD561D` |
| **等级 3** | 烈焰红 | `#FE9600` | `#FA7A18` |
| **等级 4** | 恶魔黑 | `#03001C` | `#F9A608` |

### 3.3 视觉元素规范 (Visual Elements)

#### 3.3.1 渐变应用 (Gradients)
- **万圣渐变**: `linear-gradient(135deg, #8250DF 0%, #ED6A43 100%)`

#### 3.3.2 图标 (Icons)
- 建议将某些关键图标替换为节日相关元素（如星星替换为南瓜）。

#### 3.3.3 圆角 (Border Radius)
- 延续 GitHub 标准：`6px`。

### 3.4 交互体验 (Interaction)

- **悬浮效果**：增加类似烛火晃动的微光效果。
- **加载状态**：使用跳动的南瓜或旋转的幽灵作为 Loading 动画。
