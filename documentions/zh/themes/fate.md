# 纠缠之缘 (Intertwined Fate) 主题设计语言

本设计语言以《原神》中的“纠缠之缘”为灵感核心，旨在通过星空般的深邃蓝色与梦幻的粉色交织，营造出一种命运感与神秘感。

## 1. 安装

使用 npm 或 pnpm 安装主题包：

```bash
npm install @sxo/theme-fate
# 或者
pnpm add @sxo/theme-fate
```

## 2. 适用场景

- **二次元/游戏社区**：完美契合游戏相关的内容展示。
- **个性化 2C 产品**：适用于追求独特视觉风格的消费级应用。
- **同人站/艺术作品集**：梦幻的色彩适合展示创意内容。

## 3. 设计语言

### 3.1 核心设计理念 (Core Concept)

- **关键词**：星辰、命运、交织、纯净。
- **视觉风格**：采用半透明毛玻璃效果（Glassmorphism），模拟纠缠之缘晶莹剔透的质感。
- **光影处理**：强调发光感（Glow），如同星核散发的光芒。

### 3.2 色彩系统 (Color System)

白天和黑夜模式使用相同的色相，通过调整亮度（Brightness）和饱和度（Saturation）来区分。

#### 3.2.1 基础色 (Base Colors)

| 类型 | 色相 | 白天模式 (Light) | 黑夜模式 (Dark) | 用途 |
| :--- | :--- | :--- | :--- | :--- |
| **主色** | **蓝色 (Blue)** | `#4A90E2` | `#1B3B5F` | 背景、主要操作、导航 |
| **辅色** | **粉色 (Pink)** | `#F06292` | `#880E4F` | 关键高亮、进度条、心动元素 |
| **点缀** | **紫色 (Purple)** | `#9B59B6` | `#4A235A` | 渐变过渡、阴影、特殊状态 |
| **点缀** | **绿色 (Green)** | `#48C9B0` | `#0E6251` | 成功提示、星尘效果 |
| **点缀** | **橙色 (Orange)** | `#F39C12` | `#935116` | 警告、星核中心、稀有度提示 |

#### 3.2.2 背景与文字 (Surface & Text)

| 类型 | 白天模式 (Light) | 黑夜模式 (Dark) |
| :--- | :--- | :--- |
| **主背景** | `#F5F7FA` (带淡淡的蓝调) | `#0B0E14` (深空蓝黑) |
| **容器背景** | `rgba(255, 255, 255, 0.8)` | `rgba(27, 59, 95, 0.4)` |
| **主要文字** | `#2C3E50` | `#E0E6ED` |
| **次要文字** | `#7F8C8D` | `#94A3B8` |

### 3.3 视觉元素规范 (Visual Elements)

#### 3.3.1 渐变应用 (Gradients)
- **命运渐变 (Fate Gradient)**: `linear-gradient(135deg, #4A90E2 0%, #F06292 100%)`
- **星空渐变 (Starry Gradient)**: `radial-gradient(circle at center, #1B3B5F 0%, #0B0E14 100%)`

#### 3.3.2 阴影与光效 (Shadows & Glow)
- **标准阴影**：使用带有主色的有色阴影，增加通透感。
- **星核发光**：对于按钮或关键图标，使用 `box-shadow: 0 0 15px rgba(240, 98, 146, 0.5)`。

#### 3.3.3 圆角 (Border Radius)
- 采用大圆角设计（如 `16px` 或 `24px`），模拟球形与圆润感。

### 3.4 交互体验 (Interaction)

- **悬浮效果**：鼠标悬浮时增加亮度，并产生轻微的缩放（Scale: 1.05）。
- **过渡动画**：所有状态切换应如流星般平滑，推荐使用 `cubic-bezier(0.4, 0, 0.2, 1)`。
