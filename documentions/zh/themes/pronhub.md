# PronHub 风格主题设计语言

本设计语言仿照知名视频网站的视觉风格，以极高对比度的黑、黄（橙）配色为核心，营造出强烈的视觉冲击力和专业感。

## 1. 安装

使用 npm 或 pnpm 安装主题包：

```bash
npm install @sxo/theme-pronhub
# 或者
pnpm add @sxo/theme-pronhub
```

## 2. 适用场景

- **创意/艺术类产品**：极高对比度的配色有助于突出视觉内容。
- **娱乐类应用**：具有极高辨识度的视觉风格，适合营造沉浸式体验。
- **暗黑模式优先项目**：以黑色为基调的设计，适合需要强烈视觉风格的项目。

## 3. 设计语言

### 3.1 核心设计理念 (Core Concept)

- **关键词**：高对比、沉浸式、警示、专业。
- **视觉风格**：深色模式为主，使用大面积的黑色背景以突出内容。
- **核心元素**：标志性的“黑底黄字”圆角矩形标签。

### 3.2 色彩系统 (Color System)

#### 3.2.1 基础色 (Base Colors)

| 类型 | 色相 | 白天模式 (Light) | 黑夜模式 (Dark) | 用途 |
| :--- | :--- | :--- | :--- | :--- |
| **主色** | **品牌橙 (Orange)** | `#FFA31A` | `#FF9900` | 标志性标签背景、进度条、按钮 |
| **背景色** | **极简黑 (Black)** | `#1B1B1B` | `#000000` | 核心背景、容器、侧边栏 |
| **文字色** | **纯净白 (White)** | `#FFFFFF` | `#FFFFFF` | 主文字、反白文字 |
| **辅助色** | **深灰色 (Dark Gray)** | `#282828` | `#1A1A1A` | 次要背景、悬浮态、边框 |

#### 3.2.2 背景与文字 (Surface & Text)

| 类型 | 白天模式 (Light) | 黑夜模式 (Dark) |
| :--- | :--- | :--- |
| **主背景** | `#F4F4F4` (极少用) | `#000000` |
| **容器背景** | `#FFFFFF` | `#1B1B1B` |
| **主要文字** | `#212121` | `#FFFFFF` |
| **次要文字** | `#757575` | `#B2B2B2` |

### 3.3 视觉元素规范 (Visual Elements)

#### 3.3.1 标志性标签 (The Hub Tag)
- **背景**: `#FF9900`
- **文字**: `#000000`
- **圆角**: `4px`
- **字体**: 加粗 (Bold)

#### 3.3.2 阴影 (Shadows)
- 基本不使用阴影，依靠色块区分层次。

#### 3.3.3 圆角 (Border Radius)
- **标准圆角**：`4px` 或 `8px`。

### 3.4 交互体验 (Interaction)

- **悬浮效果**：主色按钮悬浮时颜色加深，背景色容器悬浮时变亮（从 `#1B1B1B` 变为 `#282828`）。
- **进度条**：采用主色（橙色），高度较窄，加载时有流光效果。
